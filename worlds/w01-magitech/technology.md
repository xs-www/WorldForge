# W01 技术与术式工程

状态：混合。工程构成与执行路径为 `canon`；微观原理与产业细节仍有 `unknown`。

## 传统施法（canon）

- 魔法师通常需要吟唱咒语；高级魔法通常还需阵法和外置魔力源。
- 以太亲和会自发补全具体施法时间与地点，并依施法意图引导魔力沿预期路径流动。
- 这种补全机制仍是未解之谜，不是已证实的神迹。

## 咒语与施法信息（canon）

咒语是信息结构，不是特定声音的共振。咒语只编码派系与效果：`I = (C, E)`；不包含绝对施法时间和地点。完整施法为 `S = (I, T, L, M)`，其中 `T` 为时序上下文，`L` 为地点、目标或空间参考，`M` 为魔力输入与流向。

相对参数是否属于效果 `E` 的内部参数仍为 `unknown`；例如“延迟三秒”不等于绝对时刻，“半径五米”不等于绝对地点。

## 两条执行路径（canon）

- 传统法师：吟唱派系与效果 → 以太亲和补全时空上下文 → 亲和引导魔力 → 法术显化。
- 魔导器：咒术芯片 + 定位器 + 计时器 + 符文通路 + 供能 → 法术显化。

## 魔导器核心部件（canon）

| 部件 | 职责 |
| --- | --- |
| 咒术芯片 | 蚀刻派系与效果信息 |
| 定位器 | 提供地点、目标或空间定位 |
| 计时器 | 提供施法时序上下文 |
| 符文通路 | 规整并引导魔力流向 |
| 能源接口 / 蓄魔器 | 外接魔力或内置供能 |
| 操作机构 | 输入魔力或用开关触发 |

满足条件的魔导器可由普通使用者操作施法，无需法师亲自吟唱。符文通路负责规整和导向魔力；咒术芯片通过蚀刻保存部分施法信息。

材料、制造工艺、芯片可重写性、精度、术式触发原理、是否完全无声及信息语言的形式语法均为 `unknown`。把工程诊断概括为“触发 → 采集上下文 → 构成术式 → 调整魔力 → 执行 → 结束”仅为 `proposed`，不是微观定律。
