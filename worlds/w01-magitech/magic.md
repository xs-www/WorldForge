# W01 魔法体系

## 法师等级（canon）

1. 魔法学徒
2. 魔法师
3. 大魔法师
4. 至尊法师

考核标准、法术权限、人口比例与社会资格为 `unknown`。等级判断必须区分魔力储量、以太亲和、法术知识和术式控制力，不能把外置魔力容量直接视为法师等级。

## 十一种魔法派系（canon）

| 层次 | 派系 |
| --- | --- |
| 基础 | 火、水、土、风、电 |
| 高阶 | 光明、黑暗、生命、死亡 |
| 更高层 | 时间、空间 |

“层次”究竟表示学习难度、施法复杂度、知识门槛还是本体论等级仍为 `unknown`。各派系边界、组合规则及时间、空间法术的因果限制未定；高层派系不必然拥有更强破坏力。
