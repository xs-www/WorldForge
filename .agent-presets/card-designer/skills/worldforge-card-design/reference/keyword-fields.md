# 关键词规范字段

写新关键词时以 `templates/keyword.md` 为真实字段契约，本文件只补充审查标准。

| 字段 | 合格标准 | 常见问题 |
|---|---|---|
| `id` | 稳定的 `KEY-###` | 复用已废弃 ID |
| 名称 | 原创、简短、可理解 | 直接翻译同类 IP 关键词 |
| 规则定义 | 离开具体卡牌仍成立 | 只描述一张卡 |
| 钩子类型 | 权限、目标约束、替换或触发 | 只写“特殊效果” |
| 触发时机 | 明确事件与结算位置 | 不写时机 |
| 反制 | 至少一种实际应对 | 无条件且不可互动 |
| 边界测试 | 至少一个具体失败或冲突场景 | 只有顺利触发示例 |
| 状态 | 未批准时为 `proposed` | 擅自写成 `canon` |

新增前回答：

1. 现有原语为什么不能表达？
2. 是否需要新的运行时钩子？
3. 同类效果同时作用时按什么顺序结算？
4. 随机性如何定义并复现？
5. 是否引入无来源能量、无限神力或万能效果？
