# 结构化内容块

以下是当前产品写作助手的内容块摘要。实现真值仍在 `ai-content-specs.mjs`；字段发生变化时应同步更新本文件。

所有非背景故事类型通常共享：`name`、`summary`、`details`、三个类型属性、`constraints`、`openQuestions`、`relations`。`relations` 只能引用当前上下文已有 ID。

| 类型 | 专项重点 |
|---|---|
| `world` | 题材、时代、尺度；能源、生产、通信与神性边界 |
| `location` | 详细设定、环境与交通、地理角色、管辖主体、人口规模 |
| `faction` | 势力类型、领导者、总部；利益、资源和内部矛盾 |
| `character` | 叙事身份、年龄阶段、种族；欲望、选择与能力边界 |
| `species` | 起源、寿命、核心特征；生物属性与文化分开 |
| `culture` | 地区、语言、习俗；历史、迁徙与交流造成的变化 |
| `religion` | 崇拜对象、教义、组织；信仰不得自动成为客观事实 |
| `magic` | 力量来源、施展成本、硬性限制、失败与反制 |
| `technology` | 成熟度、能源、社会影响、制造维护与基础设施 |
| `item` | 类型、持有者、状态、维护、流转与使用条件 |
| `event` | 时间、地点、参与者、因果和不同立场 |
| `timeline` | `dateLabel`、`order`、史料正文；容器不使用节点排序字段 |
| `story` | `name` 与 `details`；正文以场景和行动推进 |
