# ADR-0015：宏观规则演化与局部 LLM 提案分层

- 状态：canon（技术边界）
- 日期：2026-10-15
- 决策者：作者
- 来源：作者明确要求仿照架空地图模拟器进行宏观变动，并把 LLM 用于局部精细模拟

## 背景

W99 能源危机验证了 Tick、审计、快照和重放，但它只是单资源管线测试，不是作者所说的世界模拟。若让 LLM 直接生成整张地图的新状态，结果既不可重放，也难以区分叙事提案与权威事实。

## 决策

1. 新建完全合成且非正史的 W98 群陆实验：12 个地区、3 个政体，以季度为宏观步长。
2. 人口、粮食、工业、财政、稳定度、迁徙、贸易、外交关系和边界压力由确定性规则引擎结算；相同初态、随机种子与行动得到相同快照哈希。
3. UI 以地图为主界面，允许按政体、人口、粮食和稳定度观察；W99 移入折叠的开发诊断区。
4. LLM 只接收选中地区、所属政体、相邻地区、公开关系、近期局部事件及行动目录组成的有限上下文。它只能提出一个结构化局部行动，不能提交任意状态补丁。
5. 局部行动必须经所有权、财政、参数和邻接规则校验，并由作者点击采纳后才随下一季度结算。模型不可用、超时或返回非法结果时，提供规则回退提案，宏观时钟不依赖模型。
6. W98 与 W99 均为 `proposed / experimental` 技术夹具，不改变 W01 canon；当前数值只用于验证系统行为，不声明已经平衡。

## 验收条件

- 初始地图固定为 12 地区、3 政体，至少连续推进 4 个季度并生成可见趋势与事件。
- 每季度状态写入独立模拟数据库，并可从 Tick 0 和 `macro.state_committed` 事件重放到相同哈希。
- LLM 上下文不包含未选中的全世界地区集合；越区提案、非本国地区干预和财政不足会被规则拒绝。
- 无模型配置或模型失败时仍可推进宏观世界。
- 地图、局部详情、提案采纳和季度控制在桌面与窄屏均可操作。

## 影响与限制

- 这是首个宏观模拟 MVP，不是通用机制插件：规则目前集中在 W98 引擎，尚未进入正式机制注册表。
- 当前 LLM 调用复用既有模型代理，但尚未接入多层预算调度器、费用审计和 `local_only` 路由。
- 当前边界变化是年度阈值规则，尚无战争战役、人物级精细化、暂停任务或分支历史。
