# ADR-0016：卡牌类型数值与描述编译顺序

- 状态：canon
- 日期：2026-10-15
- 决策者：作者

## 背景

既有编辑器把费用、攻击与生命显示在所有卡牌上，无法表达法术无战斗属性、武器以耐久替代生命的差异；关键词与普通文本也缺少稳定的展示编译顺序。

## 决策

1. 随从使用费用、攻击、生命。
2. 法术只使用费用，不具有攻击、生命或耐久。
3. 武器使用费用、攻击、耐久；稳定内部类型继续使用 `equipment` 兼容旧数据。
4. 旧武器草案缺少 `durability` 时，以原 `health` 迁移为耐久；法术读取时清除旧攻击与生命语义。
5. 关键词引用保持作者添加顺序。卡牌描述展示按“无附加说明关键词 → 带附加说明关键词 → 普通规则文本”稳定编译；编辑项可以逐行排列，但最终卡面使用同一规则框连续排版、自动换行，关键词名加粗，普通文本在关键词组后另起一段。
6. 卡牌库、原画集和创建/编辑器使用互斥独立界面；卡牌库负责搜索、类型/稀有度筛选和分页，点击卡牌进入编辑器。
7. 卡牌库展示由卡牌数据、原画裁剪和当前底框即时编译的 PNG，不再用多个 HTML 块拼装卡面；PNG 是可再生展示产物，不进入正史数据字段。
8. 卡牌描述仅支持 `<b>...</b>` / `**...**` 粗体与 `<i>...</i>` / `*...*` 斜体。编译结果由样式片段和纯文本组成，DOM 预览只创建文本节点，Canvas 只绘制文字；其他 HTML 不解析、不执行。
9. 属性圆章只显示数值，不在圆章下方重复显示“费用 / 攻击 / 生命 / 耐久”名称；输入控件保留无障碍名称。

## 边界

- 本决策确认编辑数据和展示语义，不确认伤害结算、耐久消耗时机或法术目标规则。
- 参考同类 DIY 工具的信息组织，不复制第三方卡框、品牌、图标、专有素材或标志性规则文本。
