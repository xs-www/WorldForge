# ADR-0002：关键词引用可携带卡牌级附加说明

- 状态：canon
- 日期：2026-10-11
- 决策者：作者

## 背景

作者确认部分关键词可以独立出现，另一些关键词在卡牌文本中需要后接本卡专属说明，例如“关键词：附加说明”。

## 决策

1. 关键词定义继续保存名称与通用规则说明。
2. 卡牌对关键词的每次引用可以携带可选的 `detail` 字段。
3. `detail` 为空时只显示关键词名称；非空时使用“关键词：detail”的格式。
4. `detail` 属于卡牌规则文本的一部分，不会反向修改关键词定义。
5. 旧版仅保存关键词 ID 的浏览器草案兼容为 `detail` 为空的引用。

## 边界

- 本决策不批准“战吼”或任何其他具体关键词，也不复制第三方关键词规则。
- 暂不允许同一卡牌重复引用同一关键词；如未来需要多个独立实例，应另行规定结算顺序。
- `detail` 当前为可读文本，结构化效果仍由 `effects` 单独描述。

## 影响范围

- `mechanics/glossary.md`
- `cards/schema/card.schema.json`
- `templates/card.yaml`
- HTML 卡牌编辑器与本地导出数据
