# ADR-0018：编辑器预览与编译卡面共用几何，原画集覆盖全量素材

- 状态：canon（技术边界）
- 日期：2026-10-15
- 决策者：作者
- 来源：作者要求“编辑/新建时的预览界面按照编译卡牌后的界面渲染”，并把原画集改为全量原画集

## 背景

编辑器里的可编辑卡面是 DOM，卡牌库与保存结果是 660×920 的 Canvas 编译 PNG。两者此前各自维护一套坐标：预览把名称放在最上方、描述框压在原画下半部，编译 PNG 则把名称横幅放在原画下方、规则框单独成区。作者在编辑时看到的不是最终会得到的卡面。

原画集此前只由已保存卡牌反查原画，素材库里生成过、但当前未绑定到任何卡牌的候选原画完全不可见，无法被重新选用。

## 决策

1. 预览卡固定为 330×460，编译 PNG 固定为 660×920，即**预览 = PNG ÷ 2**。卡面元素坐标以 PNG 坐标为单一事实源，预览使用其一半。
2. 几何固定为：原画窗按类型取 `artRect()`；名称横幅 `76,464,508×74`；规则框 `78,548,504×242`；费用圆心 `(78,76)`、攻击 `(92,826)`、生命或耐久 `(568,826)`，半径均为 48；子类型文字基线 `y=826`。
3. `tests/subpath-routing.test.mjs` 用 `artRect()` 常量与预览 CSS 做交叉断言；改动任一侧几何都会让测试失败，避免再次漂移。
4. 预览保留卡面内直接编辑（费用、攻击、生命或耐久、名称都在卡面内输入），并通过 `z-index` 让名称横幅与规则框绘制在原画之上，与编译绘制顺序一致。
5. 原画集改为覆盖素材库全部原画：数据源从“已保存卡牌反查”改为 `artAssets` 全量，并排除 `provenance === 'user_reference'` 的上传参考图。
6. 原画集新增分类筛选，默认“已使用原画”，可切换“未使用原画”与“全部原画”。已使用 = 被至少一张已保存卡牌绑定，或仍绑定到存在的设定条目。
7. 未使用素材以虚线边框与去饱和缩略图区分，仍可点开大图查看；该分类只改变展示，不删除、不重新绑定任何资产。

## 边界

- 不改变编译 PNG 的几何与绘制顺序，只对齐预览。
- 预览与 PNG 的字体渲染仍分别由 DOM 与 Canvas 完成，字形与换行不会逐像素一致；本决策保证的是位置、尺寸与层级一致。
- 原画集不提供删除、批量清理或重新绑定入口。

## 影响范围

- `dist/app.js`、`dist/index.html`、`dist/styles.css`
- `tests/subpath-routing.test.mjs`

## 未解决问题

- 是否把预览改为直接展示实时编译的 PNG：可获得逐像素一致，但会失去卡面内的直接编辑。
- 未使用素材的清理与回收策略。
