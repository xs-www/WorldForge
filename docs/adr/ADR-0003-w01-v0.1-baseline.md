# ADR-0003：导入 W01 设定集 V0.1

- 状态：canon
- 日期：2026-10-11
- 决策者：作者
- 来源：作者提供《W01 魔导工业世界设定集 V0.1》

## 背景

作者要求将 W01 V0.1 设定集导入 Worldforge。原稿已使用“已确定、推导、提案、待定”区分事实层次。

## 决策

1. 原稿“已确定”映射为 `canon`。
2. 原稿“推导”与“提案”映射为 `proposed`。
3. 原稿“待定”映射为 `unknown`。
4. W01 的正史核心更新为：蒸汽工业与魔法长期共存，蕴魔矿自古被利用，近代魔导工艺是传统施法的工程化实现。
5. 以太与魔力、两类矿物、法师等级、十一派系、施法信息结构、魔导器部件及技术史基线按原稿状态归档。

## 重要边界

- 魔法天赋来源、神性秩序、能量回流微观机制与人工逆向转换保持 `unknown`。
- 能量守恒为正史，任何人工逆向转换提案必须避免永动循环。
- 咒语只编码派系与效果；施法时间、地点和魔力输入来自外部上下文。
- 蕴魔矿和蓄魔矿不得混同。

## 影响范围

- `docs/PROJECT_DESIGN.md`
- `worlds/w01-magitech/`
- HTML 世界观架构模块
- `CHANGELOG.md` 与 `todo.md`
