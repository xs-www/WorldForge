# ADR-0017：随从种族与法术派系的卡面字段

- 状态：canon（技术边界）；随从种族词表为 `proposed` 候选，等待作者裁定
- 日期：2026-10-15
- 决策者：作者
- 来源：作者要求按同类卡牌对战产品的排布，为随从增加种族、为法术增加派系

## 背景

ADR-0016 固化了三类卡的类型数值，但随从与法术只靠数值和规则文本区分，卡面缺少表达“这是什么生物 / 这是什么派系的法术”的稳定字段。

W01 已有可直接复用的派系 canon：`worlds/w01-magitech/magic.md` 定义十一种魔法派系（基础火、水、土、风、电；高阶光明、黑暗、生命、死亡；更高层时间、空间），`technology.md` 定义咒语只编码派系与效果 `I = (C, E)`。法术派系因此是正史字段的落地，不需要新增设定。

随从种族在仓库内**没有** canon 基线：`worlds/w01-magitech/` 下人物、势力、地点、事件仍为空索引。种族属于世界观方向问题，Agent 不得自行写成正史。

## 候选方案与代价

### A. 种族与派系都使用代码内固定词表（选择）

- 优点：与既有卡牌类型、稀有度词表一致；零迁移、零新表；编辑器与卡面改动最小。
- 代价：改词表需要改代码；种族分类暂不进入资料库，无法像设定条目那样被检索和引用。

### B. 种族引用资料库「种族」条目

- 优点：最可追溯，与 13 类资料一致。
- 代价：作者必须先建立种族条目，否则选择器为空；跨卡组的机制标签与资料条目生命周期耦合。

### C. 作者可编辑的种族/派系目录

- 优点：最灵活。
- 代价：需要新增表、前向迁移、API 与整套管理界面，超出当前需求。

## 决策

1. 随从新增 `tribeId`（种族），法术新增 `spellSchoolId`（派系）。两者互斥：随从只保留种族，法术只保留派系。
2. 武器不参与种族与派系。切换类型时，不适用于该类型的字段由 `normalizeSubtype()` 清空，不保留旧值，避免「武器带着旧种族」这类脏数据。
3. 法术派系词表取自 W01 canon 的十一种魔法派系，保留基础 / 高阶 / 更高层三个层次，并在编辑器中按层次分组显示。该词表标记为 `canon`。
4. 随从种族使用代码内固定候选词表，当前候选为：**人类、构装体、蒸汽机械、亡灵、野兽**。该词表标记为 `proposed`，不是正史，作者可增删改。其中「人类」有 canon 依据（`physics.md`：只有部分人类能感知以太），「构装体」「蒸汽机械」有魔导器与蒸汽工业依据，「亡灵」有死亡派系依据，「野兽」为无锚点的通用占位，可优先裁掉。
5. 未知或越界的种族/派系 ID 在读取时丢弃为空字符串，不进入存储。
6. 卡面排布对齐同类产品：随从种族与法术派系**都显示在卡面底部中央**，与底部属性圆章同一高度。编辑器预览与编译 PNG 使用同一排布，几何单一事实源见 [ADR-0018](ADR-0018-preview-parity-and-full-artwork-gallery.md)。
7. 种族与派系当前只是展示与检索元数据，不产生任何战斗机制、克制关系或构筑限制；在基础对战规则确认前不建立正式卡池。
8. 卡牌库搜索命中范围加入种族与派系文本。
9. 完整 JSON 导出结构与 SQLite 物理 Schema 均不变，新字段随卡牌对象自然导出。

## 边界

- 本决策确认字段、词表来源与显示位置，不确认种族与派系是否参与结算、是否有克制或联动。
- 不引入种族/派系以外的同类产品字段（例如武器类型、法术目标类型）。
- 参考同类产品卡面的信息层级，不复制其种族与派系名称表、卡框、图标或素材。

## 影响范围

- `dist/cards.js`、`dist/app.js`、`dist/index.html`、`dist/styles.css`
- `cards/schema/card.schema.json`、`templates/card.yaml`
- `tests/cards.test.mjs`、`tests/subpath-routing.test.mjs`

## 未解决问题

- 随从种族的最终分类与命名仍待作者裁定，尚未写入任何世界条目。
- 种族与派系是否在基础对战规则中产生机制效果。
- 「更高层」的时间与空间派系是否允许出现在普通费用区间的法术上。

## 修订

- 2026-10-15：决策 6 原先把随从种族放在卡牌名称下方、法术派系放在卡面底部。作者随后要求两者统一到卡面底部，并让编辑器预览与编译卡面使用同一几何；决策 6 已按此改写，预览与 PNG 的单一几何规则另见 [ADR-0018](ADR-0018-preview-parity-and-full-artwork-gallery.md)。
