# ADR-0001：卡牌基础信息与显示位置

- 状态：canon
- 日期：2026-10-11
- 决策者：作者

## 背景

作者明确要求卡牌先采用费用、攻击、血量与关键词系统，并在卡面上直接编辑和预览这些信息。

## 决策

1. 单位卡基础数值包含费用、攻击与血量。
2. 费用位于卡面左上角，攻击位于左下角，血量位于右下角。
3. 卡牌描述位于卡面中下部，允许显示一个或多个已定义关键词。
4. 关键词拥有独立名称与规则说明；卡牌通过关键词引用关联。
5. 当前浏览器编辑器保存的卡牌与关键词均为 `proposed`，数值均为 `untested`。

关键词引用的可选卡牌级附加说明由 [ADR-0002](ADR-0002-keyword-usage-detail.md) 扩展。

## 边界

- 本决策只确认字段、关联方式和显示位置。
- 不确认费用增长、攻击流程、伤害结算、场位、卡组和胜负条件。
- 不复制第三方游戏的卡框、美术、图标、现成关键词或标志性规则文本。

## 影响范围

- `mechanics/combat-rules.md`
- `mechanics/glossary.md`
- `cards/schema/card.schema.json`
- `templates/card.yaml`
- HTML 卡牌编辑器与本地导出数据

## 未解决问题

- 非单位卡是否也需要攻击与血量？
- 关键词正式 ID、叠加、时机与反制规则如何定义？
- 费用上限、数值上限与卡面溢出规则如何处理？
