# ADR-0007：卡牌三分类、稀有度与设定来源联动

- 状态：canon
- 日期：2026-10-13
- 决策者：作者

## 背景

作者要求卡牌类型统一为随从、法术、装备，增加稀有度，并允许从人物、物品等可实体化设定条目直接建立卡牌草案。联动必须保留来源追踪，但不得绕过作者审核或改变来源设定的正史状态。

## 决策

1. 卡牌类型固定为 `minion / spell / equipment`，界面分别显示“随从 / 法术 / 装备”。
2. 稀有度固定为 `common / rare / epic / legendary`，界面分别显示“普通 / 稀有 / 史诗 / 传说”。
3. 旧类型读取时兼容迁移：`unit → minion`、`action → spell`、`asset → equipment`；未知值回落到 `minion`。
4. 卡牌通过去重后的 `loreRefs` / 文件格式 `lore_refs` 引用一个或多个设定条目。
5. 从设定条目发起联动时，只预填未保存卡牌草案的名称、所属世界、建议类型和来源。作者仍需检查卡牌效果并主动保存。
6. 所有界面卡牌保持 `proposed`，平衡状态保持 `untested`；来源条目的状态不因联动变化。

## 默认类型映射

- 角色、种族、势力 → 随从。
- 物品、科技、地点 → 装备。
- 魔法、事件 → 法术。

默认映射只减少录入步骤，作者可在保存前修改类型。世界、文化、宗教、编年史和背景故事不提供直接生成按钮，但可在卡牌编辑器中作为补充来源引用。

## 边界

- 稀有度当前只用于分类与展示，不代表掉落概率、构筑数量或强度承诺。
- 法术和装备暂时继续保留攻击、血量字段以兼容既有编辑器与数据；其正式数值语义等待基础对战规则裁定。
- 本决策不授权自动生成规则文本，不把设定叙述直接转换为卡牌效果。

## 影响范围

- `cards/schema/card.schema.json`
- `templates/card.yaml`
- HTML 卡牌编辑器、完整 JSON 导出与旧本地数据读取
- `docs/PROJECT_DESIGN.md`
