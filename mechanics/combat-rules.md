# 基础对战规则

## 已确认的卡牌基础信息

依据 [ADR-0001](../docs/adr/ADR-0001-card-surface-baseline.md) 与 [ADR-0007](../docs/adr/ADR-0007-card-types-rarity-lore-linkage.md)，卡牌分为随从、法术、装备，并记录普通、稀有、史诗、传说四档稀有度。当前卡面基础信息包含：

- 费用：显示在卡面左上角，数值不得为负。
- 攻击：显示在卡面左下角，数值不得为负。
- 血量：显示在卡面右下角，数值至少为 1。
- 描述：显示在卡面中下部，可引用项目内已定义的关键词。

以上只确认数据字段、分类和显示位置，不代表稀有度概率、构筑限制、资源增长、攻击流程、伤害结算或关键词语义已经确定。法术与装备暂时保留攻击、血量字段以兼容现有数据，其正式语义仍待确认。

## 仍待确认

状态：`proposed`。费用获取方式、卡组、场位、回合结构、攻击规则、伤害结算与胜负条件均未裁定。

## W97 实验对战参数

下列参数只用于 [ADR-0028](../docs/adr/ADR-0028-experimental-card-battle.md) 的可玩纵切，状态为 `experimental / untested`，不代表「仍待确认」事项已转为正式规则。

- 双方初始 20 生命，各使用 10 张 W97 合成测试牌，起手 3 张。
- 回合资源由 1 递增到 10，回合开始时补满并抽 1 张牌。
- 每方最多同时拥有 5 个随从；普通随从登场当回合不能攻击。
- 随从交战为同时互相造成攻击力数值的伤害。牌库耗尽后每次抽牌承受递增疲劳伤害。
- 法术暂只允许 `deal_damage / heal / draw_card` 三种结构化操作。
- 任一英雄生命为 0 时结束；同一结算中双方同时为 0 则平局。
