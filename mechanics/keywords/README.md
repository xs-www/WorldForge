# 关键词索引

当前没有已批准关键词。

W97 对战纵切提供四个 `proposed / experimental` 关键词，仅用于验证受控运行时：

- `KEY-001` 疾启：权限型，允许随从在登场回合攻击。
- `KEY-002` 护持：目标约束型，修改敌方普通攻击的合法目标集。
- `KEY-003` 隔绝：替换型，把第一次所受伤害改为 0，然后移除自身。
- `KEY-004` 余响：触发型，被消灭后结算一个通过白名单校验的效果。

卡牌的 `keywordUsages[].detail` 仍为纯展示文字，不参与结算。引擎只执行注册表中已知的关键词 ID 与效果原语，不解析自由文本或用户脚本。
